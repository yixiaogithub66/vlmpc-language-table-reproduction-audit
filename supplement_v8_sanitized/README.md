# Sanitized v8 Supplement

This directory is safe to attach as a supplementary summary package. It contains derived CSVs and a source snapshot: no API key, gateway URL, absolute local path, virtual environment, raw log, or model weight is included.

The complete public revision artifact is available at https://github.com/yixiaogithub66/vlmpc-language-table-reproduction-audit (release v1.0.1).

The revision_20260919 directory contains the nine-run target-image matrix, its aggregate statistics, the paired semantic-fault audit, fresh matched natural-event digests, and a redacted experiment manifest. The target-image files distinguish pre-satisfied runs from active control trials. The semantic-fault files distinguish explicitly forced synthetic queries from natural detector events.

The authoritative manuscript statistics use sample standard deviation. The final 18-run Semantic MPC source is data/semantic_mpc_authoritative_runs_v8.csv at the repository root; superseded Semantic MPC rows are excluded from v1.0.1. SOURCE_SNAPSHOT_PROVENANCE_v8.md and data/code_manifest_v8.csv distinguish the executed source from the sanitized public snapshot.
