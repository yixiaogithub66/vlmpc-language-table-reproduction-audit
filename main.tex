\begin{abstract}
Reliable evaluation of vision-language model predictive control (VLMPC) requires knowing not only whether a task succeeds, but which component selects the target and which component controls the executed action. We introduce a traceable execution-authority audit for a VLMPC-style Language-Table system that separates semantic grounding, planner authority, feedback source, and closed-loop completion across matched runs. The audit reveals a sharp feedback-source bottleneck: raw video-prediction MPC reaches 0/16 at the $\distw^{\mathrm{final}}\leq0.08$ tolerance, while a matched semantic controller succeeds in 6/6 runs with oracle state and 0/6 with detector/tracker feedback; the paired visual-minus-oracle final-distance gap is $0.2548\pm0.1453$. Grounded-controller logs further show that state feedback replaces 23/23 raw actions in every audited run, making execution authority directly observable. The semantic layer is effective when evaluated independently: strict no-cache language trials achieve 9/9 target-selection matches and 9/9 joint controls, and a target-image matrix achieves 8/9 semantic matches and 8/9 joint active successes. Re-query experiments separate mechanism capability from trigger benefit: a forced query repairs 6/6 injected semantic faults and yields 5/6 true-target successes versus 0/6 without re-query, whereas matched natural-event controls preserve identical final distances. Together, these results turn aggregate success rates into component-level evidence and provide a reusable protocol for locating whether a vision-language controller is limited by grounding, action authority, feedback estimation, or recovery logic.
\end{abstract}

\section{Introduction}
Vision-language manipulation must solve two coupled problems: infer what the instruction refers to and execute how the object should move. Model predictive control (MPC) provides a natural receding-horizon mechanism for the second problem \cite{mayne2000mpc,rawlings2017mpc}, while vision-language models (VLMs) provide semantic grounding for the first \cite{ahn2022saycan,brohan2023rt2,huang2022inner}. Their combination is attractive for tasks such as Language-Table pushing, where a controller must identify a named or pictured object, maintain its state, choose a feasible action, and recover when the semantic or visual state becomes stale.

VLMPC couples semantic evaluation with candidate-action prediction inside a visual MPC loop \cite{zhao2024vlmpc}; trajectory-level variants further reduce the burden of full video prediction \cite{chen2025trajvlmpc}. Yet an aggregate success rate does not reveal which module produced that success. A correct target can be paired with an ineffective controller; a stable execution can be produced after the raw planner action is replaced; and a re-query can fire without changing the outcome. This attribution problem is especially important in reproduction studies, because semantic correctness, planner authority, feedback quality, and final task completion can otherwise collapse into a single number.

We address this problem with an execution-authority audit that makes four quantities explicit for every branch: the requested and selected target, the source of control state, the action that is actually executed, and the final target-relative outcome. The audit evaluates an unmodified video-prediction chain, a grounded branch that logs and then corrects raw actions, a semantic state-feedback branch, matched oracle and detector/tracker feedback, language and target-image grounding, and event-triggered re-query. Figure~\ref{fig:method} summarizes this decomposition. Its central advantage is attribution: each positive or negative result identifies a specific layer rather than being assigned to the full pipeline.

The resulting evidence isolates a clear technical bottleneck. Across seeds 45--50, the same fixed-target semantic controller succeeds in 6/6 runs with oracle state and 0/6 with detector/tracker estimates, with a paired final-distance gap of $0.2548\pm0.1453$. At the semantic layer, independent strict no-cache trials reach 9/9 language target-selection matches and 8/9 target-image matches. At the recovery layer, forced re-query repairs 6/6 injected semantic faults and reaches 5/6 true-target successes, compared with 0/6 for paired no-requery controls. These results show that the audited system's strongest separation lies in feedback estimation and execution authority, while semantic grounding and controlled recovery are independently measurable capabilities.

The contributions are:
\begin{enumerate}
\setlength{\itemsep}{0pt}
\item An execution-authority protocol that separates semantic selection, state source, raw planner output, executed action, and target-relative success for every controller branch.
\item A matched feedback-source experiment that localizes the dominant tested gap: 6/6 success with oracle state versus 0/6 with detector/tracker estimates under the same semantic controller and seeds.
\item Independent grounding and recovery evaluations comprising nine language trials, nine target-image trials, matched natural-event controls, and a six-seed semantic-fault intervention.
\item A file-traceable evidence package with per-run CSVs, source and asset hashes, cache accounting, publication figures, and automated consistency checks that bind manuscript claims to executable artifacts.
\end{enumerate}

\section{Related Work}
\subsection{Visual MPC and Video-Prediction Control}
Visual MPC uses learned visual dynamics to support model-based manipulation directly in image space. Deep visual foresight and related visual MPC systems showed that action-conditioned video prediction can guide robot motion without a hand-designed dynamics model \cite{finn2017deep,ebert2018visual}. Such approaches are attractive for open-ended manipulation, but they are also sensitive to prediction bias, object occlusion, and long-horizon compounding errors. These limitations are relevant to our reproduction: the planner can generate candidate futures and rank actions, but the unmodified closed loop does not reliably drive the object to the selected goal region.

\subsection{Vision-Language Manipulation}
Language-conditioned manipulation has used VLMs and language models for task grounding, affordance selection, reasoning, and failure interpretation. CLIPort separates semantic ``what'' reasoning from spatial ``where'' execution \cite{shridhar2021cliport}. SayCan grounds language plans with affordances \cite{ahn2022saycan}. Inner Monologue emphasizes feedback-aware embodied reasoning \cite{huang2022inner}, and VoxPoser composes 3D value maps for robotic manipulation from language-model reasoning \cite{huang2023voxposer}. These systems motivate our use of explicit feedback and event handling: semantic decisions must be connected to low-level execution evidence, not only to high-level task labels.

\subsection{VLMPC, Trajectory Variants, and Testing}
VLMPC integrates VLM perception with MPC-style candidate-action evaluation \cite{zhao2024vlmpc}, while Traj-VLMPC reduces computational overhead through trajectory generation \cite{chen2025trajvlmpc}. Complementary evaluation work such as VLATest emphasizes robustness beyond isolated demonstrations \cite{wang2024vlatest}, and AHA shows the value of structured failure reasoning \cite{duan2024aha}. Our work contributes an attribution layer to this evaluation line: it records which module selected the target, which state source informed control, and which action actually reached the environment.

\section{Evaluation Setup and Evidence Sources}
\subsection{Task Definition}
The experiment uses Language-Table desktop pushing tasks. A target object such as \emph{red moon}, \emph{blue cube}, or \emph{yellow pentagon} should be pushed toward a designated corner. The controller input can be a fixed target label, a natural-language instruction, a target image, or a VLM-based scene selection request. The action is a planar end-effector push in the simulated table environment.

The primary metric is the final world-coordinate distance between the target object and the goal:
\begin{equation}
  \mathrm{success} = \mathbb{I}\left[\distw^{\mathrm{final}} \leq 0.08\right].
  \label{eq:success}
\end{equation}
We use the archived evaluation tolerance of 0.08 for task completion and additionally report 0.05 and 0.10 to expose threshold sensitivity. At 0.05, the grounded suites yield 0/4 and 0/8, while the semantic-MPC suite yields 3/18. The two thresholds therefore distinguish completion under the project criterion from tighter placement precision.

Each live semantic row carries an explicit evaluation scope so that its denominator matches the question being tested. The 18 selected-target control rows comprise 15 fixed-target controls, one natural-language instruction, one target-image interface control, and one scene-selection control. Language grounding is evaluated on the instruction row (1/1 requested-to-selected match and joint success), while target-image grounding is evaluated on the independent nine-run matrix (8/9); the aggregate 18/18 reports selected-target control completion.

For the new target-image matrix, we distinguish a \emph{pre-satisfied} run, for which the true target is already within the threshold before the first action, from an \emph{active control} trial, which starts outside the threshold and executes at least one action. \emph{Joint active success} requires both correct target-image semantic selection and active control success. This prevents a zero-step terminal state from being counted as controller evidence.

\subsection{Evidence Artifacts}
All numerical results in this paper are extracted from the study package. The main evidence files are:
\begin{itemize}
\setlength{\itemsep}{0pt}
\item sanitized per-run and aggregate CSVs for the fresh raw-MPC sweep, semantic suite, target-image matrix, event controls, semantic-fault audit, and visual-feedback test;
\item supplement CSVs for exact method parameters, checkpoint/code hashes, target-image selection, and VLM cache status;
\item publication figures and selected qualitative frames used as visual evidence; raw service logs and videos remain outside the sanitized public package;
\item a portable robustness-edge audit CSV covering occlusion, viewpoint proxy, brightness shift, and unknown-target rejection, together with its four input images.
\end{itemize}
  These artifacts bind every reported quantity to a run-level record. Formal VLM calls use the project's \texttt{CodexCLIClient} with the \texttt{codex} backend and GPT-5.5 alias; an isolated \texttt{CODEX\_HOME} supplies runtime configuration, and strict no-cache controls record zero cache hits. The public v1.0.10 evidence package at \url{https://github.com/yixiaogithub66/vlmpc-language-table-reproduction-audit} includes portable inputs, reproduction instructions, parameters, figure sources, and separate runtime-asset and source-snapshot manifests. Third-party model weights are obtained from their original sources.

\section{Method}
\subsection{Execution-Authority Audit}
We represent each run by the tuple $(g_{\mathrm{req}},g_{\mathrm{sel}},s_t,a_t^{\mathrm{raw}},a_t^{\mathrm{exec}},y)$: the requested target, selected target, control-state source, raw planner action, executed action, and terminal outcome. This representation separates three questions that an aggregate success rate conflates: whether semantic grounding selects the intended object, whether the planner or a feedback law controls the environment, and whether the resulting trajectory reaches the target. Figure~\ref{fig:method} maps the common input and logging pipeline to the evidence branches.

The branches act as attribution probes. The raw branch executes $a_t^{\mathrm{raw}}$; the grounded branch logs that action but executes a state-feedback correction; the semantic branch combines target selection with a state-feedback controller; and the visual-feedback branch replaces oracle state with detector/tracker estimates while retaining the semantic controller. Matched seeds and explicit state-source labels make the transition from semantic correctness to closed-loop execution directly measurable.

\subsection{Unmodified Reproduction Chain}
The unmodified reproduction follows a VLMPC-style loop. A task input is grounded to a target, candidate action sequences are sampled, a visual prediction model forecasts future observations, and a cost function ranks the candidates before the first action is executed. Controller comparison includes baseline, improved, literature, and literature-v2 settings. Parameter ablation varies sampling budget and cost settings.

This branch applies no final-action state-feedback correction, so the raw candidate-ranking output retains execution authority. It provides the reference point for the feedback-source and action-authority comparisons that follow.

\subsection{Codex CLI VLM Adapter}
Formal online VLM calls are executed through the local \texttt{CodexCLIClient}. For each \texttt{complete(prompt, image\_paths)} call, the adapter stages image attachments in an ASCII-only temporary directory when the project path contains non-ASCII characters, sends the prompt through standard input, and launches an ephemeral CLI request equivalent to
\begin{center}
\texttt{codex exec --skip-git-repo-check --ephemeral --color never}\newline
\texttt{-C <ASCII workdir> -o <temporary output> -m gpt-5.5 -i <image>}
\end{center}
The response is read from the temporary output file and parsed for target, subtask, or re-query state. An isolated \texttt{CODEX\_HOME} supplies runtime configuration while keeping credentials outside the source tree. When enabled, the cache key combines the model configuration, prompt, and image-content hashes; all formal event and language controls disable the cache and record zero cache hits. The CLI path supplies the evidence reported here, while an OpenAI-compatible backend remains available for development.

\subsection{Archived Implementation Parameters}
Table~\ref{tab:methodparams} summarizes the evaluated implementation parameters. The unmodified planner uses horizon $H=20$, action dimension 2, and a correlated-noise sampler with $\beta=0.5$. The command-line defaults are 200 samples and replan frequency 5, and the archived ablation contributes eight recorded sampling and cost configurations. The literature-style cost is
\begin{equation}
\begin{split}
J ={}& d_{\mathrm{obj,goal}} + 0.35d_{\mathrm{contact}} +0.15d_{\mathrm{arm,obj}}
 + 18.0J_{\mathrm{align}}  \\
&+24.0J_{\mathrm{obs}} -1.2\Delta d
 + 12.0\mathbb{I}[\Delta d < 1.0],
\end{split}
\label{eq:cost}
\end{equation}
with obstacle decay 42 pixels. In the close-range branch, the contact, alignment, progress-reward, and non-progress terms are changed to 0.10, 6.0, 1.8, and 20.0, respectively. These recovered values define the evaluated implementation.

\subsection{Grounded Original MPC}
Grounded original MPC isolates the effect of final-action feedback while preserving the raw planner trace. Each raw MPC action is recorded before a bounded simulator-state correction determines the action executed in the environment. Across the 12 grounded runs (4 controller-comparison runs and 8 ablation runs), every run contains 23 raw planner actions and 23 feedback overrides. The 23/23 replacement rate makes the transfer of execution authority directly observable instead of attributing the resulting trajectory to the raw planner.

The feedback action uses object, end-effector, and goal positions from simulator state. Let $\hat{d}_{\mathrm{push}}=(x_{\mathrm{goal}}-x_{\mathrm{obj}})/\|x_{\mathrm{goal}}-x_{\mathrm{obj}}\|$ and $x_{\mathrm{contact}}=x_{\mathrm{obj}}-0.06\hat{d}_{\mathrm{push}}$. The controller first stages the end effector near a side-clearance point, then moves to contact, and finally pushes:
\begin{equation}
  u_t = \mathrm{clip}\left(\alpha \hat{d}_{\mathrm{push}} +
  \beta(x_{\mathrm{contact}} - x_{\mathrm{ee}}), -0.08, 0.08\right).
  \label{eq:feedback}
\end{equation}
In the push phase, $\alpha=0.075$ and $\beta=0.45$; the stage/contact phases instead use a step-limited move of at most 0.06.

\subsection{Semantic MPC}
Semantic MPC isolates target selection from low-level state-feedback execution. It accepts fixed labels, language instructions, target images, or free VLM scene selection, then converts the selected target into a bounded feedback push. The \texttt{auto|vlm|vision} target-image interface sends the target image and current scene image to the configured VLM and asks it to choose among visible candidates. The branch retains receding-horizon execution and logging, but activates no raw video-prediction sampling budget ($N_{\mathrm{raw}}=0$); the state-feedback law has execution authority. This separation tests whether a selected semantic target can be converted into stable closed-loop control when state is available.

\subsection{Event-Triggered VLM Re-query}
Event-triggered re-query tests when semantic state should be refreshed. For the semantic branch, progress is measured in world-coordinate target distance using a stagnation window of 4 and a minimum progress threshold of 0.002. Fresh matched controls compare no-event and event-enabled runs without forcing the initial query. All controls disable the cache, record zero cache hits, and log fresh \texttt{CodexCLIClient} responses. Natural re-query fires in all three event-enabled runs; seed-matched final distances remain identical to the no-event controls. This comparison separates correct trigger execution from incremental benefit under conditions that already succeed.

A paired fault intervention then measures recovery capacity. Each of six seeds begins with the true target replaced by a deliberately wrong target (blue cube instead of red moon). The treatment issues one explicitly labeled audit re-query at step 3, whereas the control retains the corrupted target. Evaluation uses the independently specified true target. The \texttt{CodexCLIClient} treatment repairs the semantic state in 6/6 runs and reaches the true-target threshold in 5/6, compared with 0/6 for the no-requery controls. The intervention therefore provides direct evidence that re-query can restore corrupted semantic state.

An independent language-repeat audit separates language grounding from aggregate controller success. Three instructions (red moon, blue cube, and yellow pentagon) are each evaluated at seeds 42--44 through the same \texttt{CodexCLIClient} path, with the expected target specified independently of the controller output. All nine strict no-cache runs produce one fresh VLM response, match the expected target, and meet the 0.08 control threshold.

\section{Experiments}
\subsection{Evidence Design}
Three evidence groups support distinct attribution questions. \textbf{Raw planning} evaluates the four-variant, four-seed video-prediction chain and eight recorded parameter configurations. \textbf{Execution and semantic control} measures action replacement, language and image grounding, and recovery under oracle state feedback. \textbf{Feedback source} holds the semantic controller and seeds fixed while replacing oracle state with detector/tracker estimates. This design aligns each success rate with the component whose behavior it measures.

Across four controller variants and seeds 45--48, all 16 runs remain above the 0.08 tolerance, with variant means from 0.3134 to 0.3358 and an aggregate mean of 0.3245. The outcome is unchanged at 0.05 and 0.10, and the eight recorded parameter configurations also yield 0/8. In combination with the matched feedback-source experiment below, these results rule out the tested controller and parameter variants as sufficient explanations for stable execution.

\subsection{Execution-Authority and Feedback-Source Attribution}
Table~\ref{tab:diagnostic} identifies the subsystem that changes the outcome. Under the same semantic controller and seeds 45--50, oracle feedback reaches 6/6 while detector/tracker feedback reaches 0/6; the paired visual-minus-oracle final-distance gap is $0.2548\pm0.1453$. The broader semantic suite reaches 18/18 selected-target controls at the 0.08 criterion, with 15/15 fixed-target controls, one language control, one target-image interface control, and one scene-selection control. The independent target-image matrix contributes 8/9 semantic matches and joint active successes, while the language repeat audit contributes 9/9 matches and 9/9 joint controls.

The branch comparison therefore separates three claims: semantic target selection can be evaluated independently; oracle state feedback can stabilize execution; and replacing oracle state with the implemented visual estimates is the dominant tested bottleneck. At 0.05, the selected-target semantic suite reaches 3/18, so the 0.08 and 0.05 columns jointly report completion and placement precision.

\section{Discussion}
\subsection{Main Finding}
The central result is an attribution result, not an aggregate score. The raw video-prediction chain remains at 0/16, yet final-action state feedback replaces 23/23 planner actions and stabilizes every grounded run. More decisively, the same semantic controller and seeds 45--50 produce 6/6 successes with oracle state and 0/6 with detector/tracker feedback, with a paired visual-minus-oracle distance gap of $0.2548\pm0.1453$. Together, these comparisons identify feedback estimation and executed-action authority as the dominant tested determinants of closed-loop outcome.

The remaining experiments show that the higher-level mechanisms are independently functional. Strict no-cache language grounding reaches 9/9 target matches and joint controls, target-image grounding reaches 8/9, and forced re-query repairs 6/6 injected semantic faults with 5/6 true-target completions versus 0/6 controls. Natural re-query also fires in 3/3 enabled runs, although already-successful matched controls leave no distance margin for improvement. The execution-authority audit therefore converts a mixed full-pipeline outcome into specific evidence about grounding, control state, action authority, and recovery.

\subsection{Scope of the Finding}
The attribution claim is scoped to the Language-Table simulator, the listed model assets, the evaluated controller variants, and the 0.08 project criterion. Oracle and visual feedback are compared under matched seeds, but oracle-feedback success is not assigned to the raw video-prediction planner. The 18/18 semantic aggregate measures selected-target control and is complemented by independent grounding denominators of nine language and nine target-image trials. Precision is threshold-sensitive (3/18 at 0.05), and the natural-event comparison covers already-successful runs. These boundaries preserve the component-level finding while identifying the evidence needed for broader task, image, and real-camera generalization.

\subsection{From Attribution to a Visual Closed Loop}
The next step follows directly from the measured oracle-to-vision gap. Synchronized RGB/state traces can quantify target-centroid error, end-effector error, goal-distance MAE, visibility F1, and temporal consistency before the detector/tracker is re-evaluated against oracle feedback on matched seeds. The same controller interface supports confidence-gated updates without changing the semantic layer, preserving the attribution design.

Recovery and grounding should then be expanded together: more instructions and target images, randomized semantic faults and failure times, and matched no-query, forced-query, and natural-event conditions. Final distance, 0.05/0.08 success, recovery latency, query count, and runtime would extend the present component-level evidence into a broader closed-loop evaluation.

\subsection{Data and Code Availability}
The public repository at \url{https://github.com/yixiaogithub66/vlmpc-language-table-reproduction-audit} and the accompanying v1.0.10 artifact include the manuscript source, authoritative 2026-09-22 and 2026-09-23 per-run and aggregate CSVs, the portable robustness-edge CSV and inputs, exact method parameters, a reproducible figure script, source and runtime-asset manifests, and an automated consistency check. The artifact deliberately excludes credentials, private endpoint addresses, local absolute paths, virtual environments, raw service logs, and third-party model weights. Reported aggregates can be recomputed from the included portable files without cached VLM responses. End-to-end reruns additionally require independently obtained detector, tracker, and video-prediction checkpoints, the `codex` CLI, and a separately configured isolated `CODEX\_HOME` profile for the CodexCLIClient, as documented in the reproduction guide.

\section{Conclusion}
We introduced an execution-authority audit that separates target selection, state source, raw planning, executed action, and closed-loop completion in a VLMPC-style Language-Table system. The audit reveals a decisive feedback-source gap: under the same semantic controller and seeds, oracle state yields 6/6 successes and detector/tracker feedback yields 0/6, while grounded logs show 23/23 raw-action replacements in every run. Independent evaluations demonstrate 9/9 language-grounding matches, 8/9 target-image matches, and 6/6 semantic-fault repairs with 5/6 true-target completions versus 0/6 controls. These results locate the current bottleneck in visual state estimation and action authority. The audit provides a reusable way to assign component responsibility before aggregate manipulation results are interpreted.
