\begin{abstract}
Aggregate success rates obscure which component actually controls a vision-language model predictive control (VLMPC) system. We introduce an execution-authority audit for Language-Table pushing that records the requested and selected targets, state source, raw planner action, executed action, and terminal outcome. The audit localizes the dominant tested gap: the raw video-prediction chain reaches 0/16 successes, while the same semantic controller and seeds reach 6/6 with oracle state and 0/6 with detector/tracker feedback; the paired visual-minus-oracle final-distance gap is $0.2548\pm0.1453$. In grounded diagnostics, feedback replaces 23/23 raw actions in every audited run, exposing the transfer of execution authority. Independent no-cache evaluations obtain 9/9 language matches and joint controls, 8/9 target-image matches and joint active successes, and 6/6 semantic repairs with 5/6 true-target completions under forced re-query versus 0/6 without re-query. These component-level comparisons separate grounding, planning, feedback estimation, and recovery, turning a reproduction outcome into a traceable diagnosis.
\end{abstract}

\begin{IEEEkeywords}
Vision-language model predictive control, Language-Table, reproduction audit, feedback control, event re-query.
\end{IEEEkeywords}

\section{Introduction}
Vision-language manipulation couples a semantic question---what object does the instruction identify?---with a control question---how should that object be moved? Model predictive control (MPC) supplies receding-horizon action selection \cite{mayne2000mpc,rawlings2017mpc}, while vision-language models (VLMs) support task grounding \cite{ahn2022saycan,brohan2023rt2,huang2022inner}. VLMPC combines these capabilities by using semantic evaluation within a visual-prediction control loop \cite{zhao2024vlmpc}; trajectory-level variants reduce the cost of full video prediction \cite{chen2025trajvlmpc}.

The resulting pipeline is powerful but difficult to diagnose. A correct target can be paired with an ineffective controller, a successful trajectory can be produced after the raw planner action is replaced, and a re-query can fire without changing an already successful outcome. An aggregate task score cannot distinguish these cases. This ambiguity is especially consequential in reproduction studies: without an explicit record of state source and executed action, success may be assigned to a component that did not control the environment.

We address this attribution problem with an execution-authority audit. Every branch records the requested target, selected target, control-state source, raw planner action, executed action, and target-relative outcome. Matched comparisons then isolate four questions: whether the raw visual planner reaches the task criterion; whether a feedback law replaces its actions; whether oracle and visual state estimates support the same semantic controller; and whether language, target-image grounding, and re-query remain effective when evaluated independently.

The resulting evidence identifies a feedback-source bottleneck rather than a semantic one. The raw chain is 0/16, and grounded logs show that state feedback replaces 23/23 raw actions in every audited run. With the semantic controller and seeds fixed, oracle state yields 6/6 successes and detector/tracker feedback yields 0/6. Meanwhile, strict no-cache language trials reach 9/9 target matches, the target-image matrix reaches 8/9, and forced re-query repairs 6/6 injected semantic faults. The oracle-state branches are privileged diagnostics, not successful reproductions of the unmodified VLMPC chain. The contribution is therefore not another aggregate controller score, but a reusable protocol for assigning component responsibility and a file-traceable evaluation that exposes where the tested system succeeds and where the closed loop breaks.

\section{Related Work}
Visual MPC uses action-conditioned prediction to control manipulation directly from images \cite{finn2017deep,ebert2018visual}. Language-conditioned systems separate semantic and spatial reasoning in different ways: CLIPort decomposes semantic and spatial reasoning \cite{shridhar2021cliport}, SayCan combines language plans with affordances \cite{ahn2022saycan}, Inner Monologue incorporates feedback \cite{huang2022inner}, and VoxPoser constructs spatial value maps \cite{huang2023voxposer}. These systems motivate an explicit connection between high-level selection and low-level execution.

Evaluation work has also moved beyond isolated demonstrations. VLATest probes robustness \cite{wang2024vlatest}, while AHA structures failure reasoning \cite{duan2024aha}. Our audit complements these approaches by treating state source and executed-action authority as first-class evaluation variables. It is designed to answer not only whether a run succeeds, but which module supplies the information and action that produce its outcome.

\section{Execution-Authority Audit}
\subsection{Task, Metric, and Evidence}
The experiments use Language-Table desktop pushing. A fixed label, language instruction, target image, or scene-selection request identifies an object to be pushed toward a designated corner. Success is measured by the final world-coordinate target-to-goal distance,
\begin{equation}
  \mathrm{success}=\mathbb{I}[\distw^{\mathrm{final}}\leq0.08].
  \label{eq:success}
\end{equation}
The archived 0.08 tolerance is the primary criterion; 0.05 is also reported to distinguish completion from tighter placement. All counts retain their own experimental denominator. In particular, the 18-run semantic suite measures control of the selected target, whereas the independent nine-run language and target-image studies measure grounding against labels specified outside the controller.

Each run is represented as $(g_{\mathrm{req}},g_{\mathrm{sel}},s_t,a_t^{\mathrm{raw}},a_t^{\mathrm{exec}},y)$: requested and selected targets, control-state source, raw action, executed action, and terminal outcome. The repository contains per-run CSVs, exact parameter records, source and asset manifests, figure scripts, and an automated consistency check. Thus the compact tables below summarize, rather than replace, the run-level evidence.

\subsection{Attribution Branches}
Figure~\ref{fig:method} shows the common audit path. The \emph{raw} branch grounds a target, samples candidate sequences, predicts visual futures, ranks them, and executes $a_t^{\mathrm{raw}}$. Its horizon is 20 with two-dimensional actions; the default budget is 200 candidate samples with replanning every five steps. The fresh sweep uses four controller variants and four seeds, and an archived ablation covers eight sampling/cost configurations; exact costs, detector settings, event thresholds, and source hashes are supplied in the supplement.

The \emph{grounded} branch preserves and logs the raw planner call but executes a bounded simulator-state correction. The feedback law stages the end effector, establishes contact, and pushes toward the goal; the supplement provides its gains and phase thresholds. Logging both actions makes authority observable: all 12 grounded runs contain 23 raw actions and 23 replacements.

The \emph{semantic} branch accepts fixed labels, instructions, target images, or VLM scene selection and applies the same state-feedback controller to the selected target. It retains receding-horizon execution and logging, but no raw video-prediction sampling has action authority. The \emph{visual-feedback} branch holds that semantic controller and the seeds fixed while replacing simulator state with YOLO/PySOT detector-tracker estimates. This paired change isolates feedback source.

Formal language, target-image, and re-query calls use the project's \texttt{CodexCLIClient} with the GPT-5.5 model alias. Prompts are passed through standard input, images through CLI attachments, and non-ASCII paths are staged in an ASCII-only temporary directory. An isolated \texttt{CODEX\_HOME} keeps credentials outside the source tree. The reported language and event studies disable caching and record zero cache hits.

\subsection{Re-query Intervention}
Natural-event controls use a four-step stagnation window and a minimum progress of 0.002 world-distance units. Three event-enabled runs trigger a fresh query, while matched no-event runs retain identical final distances because both conditions already succeed. A separate intervention supplies the missing recovery condition: six seeds begin with the true red-moon target replaced by blue cube; treatment issues a forced audit query at step 3, whereas control retains the corrupted target. Evaluation always uses the independently specified true target.

\section{Discussion}
The audit turns a mixed full-pipeline outcome into a component-level diagnosis. Semantic grounding is strong across repeated language and target-image requests, and a fresh query can repair an injected semantic fault. Stable execution, however, depends on the state and action path: raw video prediction does not complete the task in the evaluated sweep, feedback replaces every raw action in the grounded diagnostics, and the same semantic controller separates sharply under oracle and visual feedback. This is precisely the distinction that aggregate success rates erase.

The inference is scoped to Language-Table, the listed assets, and the evaluated controller variants. Oracle-feedback runs diagnose controllability; they are not evidence that the raw visual planner succeeded. Likewise, the 18/18 semantic-suite count measures control of the selected target, while the nine-run language and target-image matrices supply independent grounding denominators. The repeated language and target-image studies use three seeds per condition, and the heterogeneous 18-row suite is not interpreted as 18 independent seeds; the grounded zero variance reflects its shared terminal feedback law. The factor-isolating audit localizes the tested boundary without claiming exhaustive causal decomposition. Input-level occlusion, brightness, viewpoint-proxy, and unknown-target tests are retained in the supplement as robustness checks rather than presented as real-world generalization.

The measured oracle-to-vision gap also defines the next experiment. Synchronized RGB/state traces should quantify target-centroid error, end-effector error, goal-distance mean absolute error, visibility F1, and temporal consistency before repeating the matched oracle-versus-vision evaluation. Confidence-gated updates can then be added without changing the semantic interface, preserving the same attribution design. Recovery can be extended with randomized fault times and matched no-query, forced-query, and natural-event conditions.

Credentials, private endpoints, local paths, raw service logs, and third-party weights are excluded; included aggregates can be recomputed from the portable files. \section{Conclusion}
We introduced an execution-authority audit that separates target selection, state source, raw planning, executed action, and task outcome. Matched evidence identifies feedback estimation and action authority as the dominant tested bottleneck, while independent evaluations verify repeated grounding and semantic-fault recovery. The protocol provides a traceable basis for assigning component responsibility before aggregate VLMPC results are interpreted.
